🌸 Iris
Бот для Discord-серверов с брачной системой, РП-действиями, модерацией и статистикой сообщений. Всё на русском, всё работает без внешних сервисов — только Python.


Быстрый старт
bashgit clone https://github.com/твой_ник/iris
cd iris
pip install discord.py
Открой config.py и вставь токен:
pythonBOT_TOKEN = "твой_токен"
Или задай переменную окружения (так надёжнее):
bashexport DISCORD_TOKEN=твой_токен
python main.py
База данных создастся сама при первом запуске.

Настройка
Всё что нужно менять живёт в config.py:

PREFIX — префикс команд (по умолчанию !)
RP_ACTIONS — шаблоны РП-действий, редактируй как хочешь
TRIGGER_PHRASES — список фраз, на которые бот реагирует мутом


Права бота
Минимально необходимые права в Discord Developer Portal:

Ban Members
Moderate Members (таймаут/мут)
View Members
Send Messages + Embed Links
Read Message History


Система рангов
Ранги хранятся в боте и не связаны с Discord-ролями. Владелец сервера всегда ранг 5.
#Название0👤 Пользователь1🛡️ Младший модератор2⚔️ Старший модератор3🔰 Младший администратор4👑 Старший администратор5⭐ Создатель
Назначение:
+модер @user          → ранг 1
+модер 2 @user        → ранг 2
повысить @user        → +1 ранг
понизить @user        → -1 ранг
снять @user           → убрать ранг
!модер @user          → ранг 1  (через восклицательные знаки)
!!модер @user         → ранг 2
!!!модер @user        → ранг 3
!!!!модер @user       → ранг 4

Модерация
КомандаРангЧто делает!бан @user [причина]2+Бан!мут @user <время> [причина]1+Таймаут (30с 10м 2ч 1д 1н)!размут @user1+Снять таймаут!банлист [стр.]2+Список банов!мутлист [стр.]1+Активные муты
Все команды работают ответом на сообщение — без упоминания.

Репорты
!репорт @user причина       — пожаловаться
!репортлист [@user] [стр.]  — посмотреть репорты (ранг 1+)
!очиститьрепорты [@user]    — удалить репорты (ранг 3+)

Профиль
!кто я              — ваш профиль
кто ты @user        — профиль другого
кто ты (ответом)    — профиль автора сообщения
кто админ           — список администрации
Принимает @упоминание, числовой ID или ссылку discord.com/users/ID.

Браки
брак @user          — сделать предложение
брак да / брак нет  — ответить на предложение
!развод             — расторгнуть брак (восстановление — 3 дня)
мой брак            — информация о вашем браке
твой брак @user     — брак другого пользователя
браки [стр.]        — все браки сервера
топ браков [стр.]   — топ по сроку
+брак рейтинг       — добавить пару в топ
-брак рейтинг       — убрать пару из топа
брак продлить <дни> — продлить срок брака
Административные (ранг 3+):
поженить пару @u1 @u2   — зарегистрировать брак принудительно
развести пару @u1 @u2   — расторгнуть принудительно
развести вышедших       — развести пары с покинувшими сервер
!сброс браков           — сбросить все браки (ранг 4+)

РП-действия
Без префикса. Работают с @упоминанием или ответом на сообщение. Причина — со второй строки.
обнять @user
поцеловать @user
укусить @user
ударить @user
убить @user
уебать @user
трахнуть @user
выебать @user
Шаблоны фраз редактируются в config.py → RP_ACTIONS.

Статистика
стата / топ              — топ активности за сутки
стата неделя             — за 7 дней
стата месяц              — за 30 дней
стата вся                — за всё время
чат стата по часам       — почасовой график за 24 часа

Развлечения
!шипперим   — рандомный шиппинг с участником сервера

Требования

Python 3.10+
discord.py >= 2.0
